# 界面视觉表达知识库

## 范围

保存可复用的界面视觉表达知识。本库不记录学习进度、掌握程度、测验结果或用户能力判断。

## 按问题检索

- 想表达“什么最重要、先看哪里”：见 [视觉层级](entries/visual-hierarchy.md)（别名：视觉优先级）。
- 想表达“哪些内容属于一组”：见 [信息分组](entries/information-grouping.md)。
- 遇到“页面很乱”：不要直接选定原因；先分别检查主次是否清楚、内容关系是否清楚，再调用对应条目。

## 八类导航

- 核心概念：视觉层级、信息分组
- 专业术语：视觉层级（视觉优先级、Visual hierarchy）、Grouping
- 工作流：观察页面 → 区分主次问题与关系问题 → 选择调整维度 → 对照验收
- 评价：注意顺序是否符合任务优先级；分组是否让内容关系可辨
- 失败模式：把“乱”直接诊断成单一问题；用层级手段代替分组，或反之

## 来源边界

本库初版仅整理用户提供的教学知识，按用户要求未联网核查。教学例子不是实际页面诊断。
