**阳台种菜：领域地图与核心概念顺序**

本次没有联网核实，内容来自通用园艺知识。播种期、农药规定、物业规定这些会随地区和时间变化的内容，最后一节列出了该去哪里核对。

## 范围

阳台种菜要解决的是：在光照、空间和承重都有限的地方，靠盆和箱种出能吃的菜。

- **本次包括**：住宅阳台和窗台的盆栽、箱栽。作物限于叶菜、香草和小型果菜（番茄、辣椒）。
- **暂不展开**：水培和鱼菜共生、屋顶大棚、果树盆栽、补光灯的具体选型。

整体顺序如下。前三步决定你能种什么；后面几步决定能不能种好；出了问题，通常要退回测光或浇水那一步。

**测光照 → 选作物 → 准备盆和土 → 播种或买苗 → 日常浇水、追肥 → 巡查病虫 → 收获和换茬**

## 领域地图

| 类别 | 内容 |
|---|---|
| 涉及的东西 | 光（阳台朝向、遮挡物、封窗玻璃）、植物（叶菜、果菜、香草）、根部环境（盆、土、水、肥）。虫、病和邻居物业是外部约束，你的时间投入决定浇水频率。 |
| 关键原理 | 光照时长决定能种什么：果菜一般要每天 6 小时以上直射，叶菜和不少香草 3–4 小时也能长。盆里的根既要水也要空气，所以排水比土壤肥力更要紧；盆土养分有限，需要追肥。 |
| 常用词 | 全日照/半日照（每天直射光的时长）、定植（苗移入最终的盆）、间苗（拔掉过密的苗）、抽薹（叶菜提前开花、叶子变苦）、见干见湿（表层干了再一次浇透）。徒长、黄叶见下面的"常见失败"。 |
| 操作流程 | 先记录一天中哪些时段有直射光，据此选作物，再配盆和土，然后播种或买苗。日常按"看土 → 浇水 → 每隔一段时间追肥 → 看叶背有没有虫"循环。出问题时退回检查光照和浇水，不要先加肥。 |
| 会用到的记录和标签 | 种子包背面：播种深度、株距、发芽天数、成熟天数，用来决定播种时间和一盆种几株。肥料包装上的氮-磷-钾比例，用来区分给叶菜还是给果菜。你自己的种植日志（照片加浇水施肥记录）是向 Agent 求助时最有用的材料。 |
| 怎么判断好坏 | 株型：茎节间短、叶色正常说明光够。盆土湿度：手指插入 2–3cm 或掂盆的重量。收成和投入是否划算。取舍在于：少浇省事但可能缺水，多浇容易烂根。 |
| 常见失败 | 徒长（茎细长、易倒）：多由光不足或播得太密引起。黄叶：可能是浇水过多烂根、缺氮，或只是老叶自然衰老。开花不结果：封闭阳台缺少授粉、高温、氮肥过多都可能导致。另有蚜虫，以及干热环境下常见的红蜘蛛，和盆土过湿引来的小黑飞（蕈蚊）。 |
| 规范与参考 | 阳台种菜没有专门的强制标准。可参考的有：各地农技部门的播种日历；农药标签上的"安全间隔期"，指最后一次用药到采摘必须间隔的天数；建筑荷载规范给阳台设的承重值（据记忆 GB 50009 为 2.5kN/m² 左右，待核对）；花盆坠落伤人要承担的法律责任。 |

## 贯穿案例（教学假设，评价结果为模拟）

- **起点**：你说"想在阳台种点能吃的"。
- **观察条件**：阳台朝东、没封窗，上午 7–11 点有直射光，约 4 小时；周末才有空。
- **选择**：光照不到 6 小时，所以放弃番茄，改种生菜、小白菜、香葱。周末才有空，就用 20cm 深、带排水孔的箱子，配能保水的通用育苗土。
- **成果片段**：`东阳台4h直射｜生菜2箱，株距约15cm｜表层2cm干了再浇到盆底出水｜播后约4周开始摘外叶`
- **模拟评价**：第 3 周苗细长、倒伏，下部叶子发黄。
  - 细长倒伏判断为徒长，原因是光不足加播得太密。处理：间苗，把箱子移到最亮的位置。
  - 黄叶先摸土，发现一直是湿的，于是减少浇水，不追肥。
  - 这两步分别退回到"测光照"和"浇水判断"。

## 导航

**起点**：先测光。它对后面所有选择的约束最强。

**向 Agent 提问时交代这些**：

- 城市或气候，以及当前月份
- 阳台朝向、每天直射光的时段、是否封窗
- 想吃的菜
- 盆的尺寸和数量、用的什么土
- 多久能浇一次水
- 有症状时附上照片，以及最近一周的浇水施肥记录

**建议比较靠谱的迹象**：

- 先问或先考虑你的光照和季节
- 按条件给建议，比如"若每天直射不足 6 小时，则……"
- 诊断时列出几种可能原因，并给出区分方法，比如"先摸土"
- 数字给范围，并说明适用条件

**危险信号**：

- 不问光照就推荐番茄
- 看到黄叶就断定缺肥
- 把大田的每亩用量直接套到盆栽上
- 推荐药剂却不提安全间隔期

**需要自己核对的**：本地播种日历、农药登记与标签、物业对外挂花盆的规定。我没有核对真实种植日志和失败复盘这类资料，建议去查本地农技推广站或高校发布的盆栽种菜指南。

## 核心概念与学习顺序

| 顺序 | 概念 | 含义与为什么排在这里 | 向 Agent 提问 / 检查它的问题 |
|---|---|---|---|
| 1 | 光照时长与作物对光的需求 | 每天有几小时直射光决定能种什么。它没有先决条件，却约束后面的一切，所以推荐从这里开始。 | "我的阳台朝东、不封窗，7–11 点有直射，按这个条件筛选作物。" |
| 1′ | 季节与温度：冷季作物和暖季作物 | 生菜、菠菜喜欢凉快，天热容易抽薹；番茄、罗勒怕冷。它和光照并列，都是选作物的前提，彼此独立。 | "现在是几月、在哪个城市，这时候能播的作物里，哪些也符合我的光照？" |
| 2 | 作物类型与收获方式 | 叶菜可以反复摘外叶；果菜周期长，还需要授粉。先懂了 1 和 1′，才能判断哪一类适合你。 | 检查 Agent 推荐的果菜有没有提授粉，尤其是在封窗阳台。 |
| 3 | 根部环境：排水与透气 | 盆土积水，根会缺氧，这比缺肥更常见。它和 1–2 相互独立，可以同时学，但必须先于第 4 项。 | "我用的是什么土、盆有没有排水孔，这样的组合是否偏保水？" |
| 4 | 浇水判断（见干见湿） | 按土的实际干湿浇水，而不是按日历浇。先决是 3：保不保水由土决定。 | 检查 Agent 是否让你先看土再浇，而不是给"每天浇多少毫升"这样的固定答案。 |
| 5 | 养分：氮-磷-钾与追肥 | 叶菜偏重氮，果菜开花后要更多磷钾；盆土的肥会被浇水冲走。先决是 2 和 4。 | "现在长到哪个阶段、用的什么肥、多久施一次，要不要调整？" |
| 6 | 症状区分：徒长、黄叶、开花不结果 | 同一个症状可能有几种原因，比如黄叶既可能是浇太多，也可能是缺肥。要先懂 1、4、5 才能区分，这是判断 Agent 建议靠不靠谱的关键。 | "列出可能原因，并告诉我先检查什么来区分它们。" |
| 7 | 病虫害与安全用药 | 先排除光、水、通风这些环境原因再考虑用药；给要吃的菜用药，必须看安全间隔期。先决是 6。 | 检查 Agent 是否先建议物理办法（冲洗、剪除），用药时是否提到了安全间隔期。 |

关于顺序：

- 严格的先决关系只有两条：3→4→5→6→7，以及 1、1′→2。
- 把光照放在第一位是教学上的建议，不是理解上的前提。
