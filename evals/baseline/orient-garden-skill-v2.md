**阳台种菜：领域地图 + 核心概念学习顺序**

> 依据说明：本次没有联网，内容来自通用园艺知识，没有逐条对照外部资料核实。播种时间、当地气候、农药适用范围这几类信息因地区和年份而异，使用前要按你所在城市再查一次。

## 一、总览与边界

阳台种菜要解决一件事：在光照、空间、土量和承重都有限的条件下，让可食用植物长好并有收成。你能控制的变量主要有五块：
- **光照**：决定能种什么
- **容器和土**：决定根系环境
- **水和肥**：日常管理
- **观察和诊断**：出了问题怎么办
- **病虫害**

骨架是这样的：**光照、温度、季节 → 选作物 → 按作物配容器和土 → 浇水施肥 → 观察症状 → 调整或换茬**。其中光照的约束最强，后面的决定大多受它限制。

**本次涵盖**：开放或封闭阳台上的盆栽种植，包括叶菜、香草、小型果菜，以及萝卜这类浅根的根菜。

**暂不展开**：水培和鱼菜共生、补光灯选型、自制堆肥、果树、楼顶或露地菜园，以及有机认证。

## 二、领域地图

| 类别 | 代表条目及关系 |
|---|---|
| **对象** | 阳台（朝向、是否封闭、楼层风）、容器、基质（盆栽用土）、植株、种子或菜苗、肥料、害虫。阳台条件**约束**作物选择。容器体积**限制**根系大小和保水量，所以夏天小盆很快就会干透。 |
| **原理** | ① **直射光时数**：这是植物制造养分的上限，要结果的菜比叶菜要求高。② **根系既要水也要空气**：积水会让根缺氧，这就是烂根的来历。③ **冷凉季和温暖季作物**：温度决定什么季节能种。④ **盆里养分有限**：盆土的养分会被吃完、被水冲走，需要追肥；氮肥偏多**可能导致**只长叶、不结果。⑤ **果菜需要授粉**：阳台上昆虫少，可能坐不住果。 |
| **常用词** | 全日照/半日照、营养土、泥炭/椰糠/珍珠岩/蛭石、底孔、见干见湿、徒长、间苗、定植、底肥/追肥、缓释肥/水溶肥、烂根（沤根）、蚜虫/红蜘蛛/白粉虱、连作、安全间隔期。这些词各自在本表对应的位置解释。 |
| **流程** | 记录阳台条件 → 按光照和季节选作物 → 配容器和土 → 播种或买苗 → 间苗、定植 → 浇水施肥 → 观察 → 收获 → 换茬、处理旧土。症状不对时，退回"浇水施肥"或"选作物/换位置"那一步重来。 |
| **记录** | 阳台条件记录（朝向、每天几点到几点有直射）、种植计划（作物、季节、容器、土）、浇水施肥日志、问题照片（注明日期）。前两份决定选什么菜，后两份用来诊断问题，也是向 Agent 提问的素材。 |
| **怎么判断好坏** | 叶色、节间长短（茎上两片叶子之间的距离，太长说明徒长）、基质干湿（用手指探 2–3 cm，或掂盆的重量）、虫的数量、产量。判断要看趋势，一张照片不够：新叶和老叶分开看，连续几天对比。 |
| **常见失败** | 徒长（光不足、太密、偏热）；黄叶（过湿缺氧、缺氮，也可能只是老叶自然衰老）；烂根（积水、盆没有底孔）；开花不结果（光不足、授粉不足、氮多、过热）；夏天萎蔫（盆小、暴晒）；红蜘蛛（干热环境容易爆发）；蚜虫（嫩梢上成片出现）。同一个症状往往有多个原因，要靠对照检查区分。 |
| **规范和指南** | 家庭阳台种菜**没有正式标准**。实际可参考的有：各地农技推广或园艺机构的种植日历（有地区性）、种子包装上的播种期和株距、农药标签（适用作物、用量、安全间隔期）。另外要注意安全：花盆掉落属于高空坠物风险，湿土很重还牵涉承重，物业和相关法规的具体要求待你本地核实。 |

## 三、贯穿案例（教学假设）

**起点**：一个朝东的开放阳台，主人想"种点能吃的"。他 3 月中旬观察了一整天，发现大约 9 点到 13 点有直射光，约 4 小时。

**选作物**：常见的园艺说法是，番茄、辣椒这类果菜要 6 小时以上直射，叶菜和部分香草 4 小时左右也能长（这是常见经验，本次没有核实出处）。所以他先种鸡毛菜、生菜和葱，番茄以后再试。

**种植计划的一行**：

> 东向，直射约 4h（3/15 实测）｜鸡毛菜、生菜｜长条盆，深约 20 cm，有底孔｜市售营养土 + 少量珍珠岩｜出苗前保湿，出苗后土表干了再浇

**评价（模拟结果）**：第 3 周，苗细长、颜色浅、容易倒。判断为徒长，候选原因有三个：光不足、太密、偏热。区分方法如下：
- 间苗后放在同一位置，新长的部分是否变短变壮？这能验证"太密"。
- 挪一盆到光最强的角落作对照。这能验证"光不足"。

**决定**：先间苗并挪到最亮处。如果还是徒长，说明光照不够这类菜，就退回"选作物/换位置"那一步：换更耐阴的菜，或考虑补光（补光不在本次范围内）。

## 四、导航

**推荐起点**：先搞懂光照。其他判断都以它为前提，而且你今天就能自己测。

**向 Agent 提问时交代这些**：
- 城市或气候区
- 阳台朝向，开放还是封闭
- 实测的直射时段
- 当前季节
- 容器尺寸和数量
- 用的什么土
- 浇水方式和频率
- 症状：什么部位、出现时间、有无照片
- 已经做过的处理
- 限制条件，比如承重、不想用农药

**回答比较可靠的迹象**：
- 推荐作物前，先问你的光照和地区
- 对症状给出多个候选原因，并告诉你怎么区分
- 浇水按土的干湿来判断
- 提到用药时，提醒看标签和安全间隔期

**需要警惕的迹象**：
- 不问光照就推荐番茄、辣椒
- 只给固定频率，比如"每天浇一次"
- 看到黄叶就断定缺某种肥
- 把大田的数据直接套到盆栽上
- 播种时间不区分地区

**证据缺口**：没有核对地区种植日历、真实阳台种植记录和失败复盘。上面的光照时数等数字都是常见经验，待核实。

## 五、核心概念与理解顺序

| 顺序 | 概念组 | 含义 | 先决项和依赖理由 | 可以这样问 Agent，或这样检查它的回答 |
|---|---|---|---|---|
| 1 | **直射光时数和朝向** | 每天有几小时太阳直接照到叶子上 | 无先决项。它限定了能种什么，后面几乎每个判断都要用 | "我家阳台朝东，实测直射 9–13 点，这个季节适合种哪些菜？按每种菜所需光照说明理由。" |
| 2 | **作物类型和季节**（叶菜/果菜/根菜；冷凉季/温暖季） | 不同的菜对光、温度、生长期要求不同 | 依赖 1。只有知道自己的光照，才能判断推荐合不合适 | 检查：推荐的作物是否同时符合我的直射时数和当季气温？ |
| 3 | **容器、基质、排水**（放在一起理解） | 根系需要水也需要空气，盆的深浅和土的配方决定两者的平衡 | 原理上可以和 1 并列学。选盆的深度要参考 2，因为不同作物根深不同 | "种生菜和小萝卜，各需要多深的盆？营养土要不要加珍珠岩？说明对排水的影响。" |
| 4 | **浇水判断** | 按土的干湿来浇，不按日程浇 | 依赖 3。同样的浇水量，放进不同的盆和土，效果完全不同 | 检查：建议里有没有"先测土湿度"？有没有区分季节和盆的大小？ |
| 5 | **养分和施肥**（底肥/追肥、氮与结果） | 盆里养分有限，不同阶段需要的养分不同 | 依赖 2、3。叶菜和果菜需求不同，土量决定要多久补一次 | "种在营养土里的小番茄，什么时候开始追肥？开花后要不要换肥？说明依据。" |
| 6 | **症状诊断**（徒长、黄叶、烂根、萎蔫） | 从现象列出候选原因，再用对照检查区分 | 依赖 1、4、5。这是它们的综合应用，不懂前面几项就分不清原因 | "新叶发黄、老叶正常，土一直偏湿，附照片。请列出候选原因和区分它们的检查办法。" |
| 7a | **病虫害**（分支） | 认虫、早发现，先用隔离、冲洗等物理办法，用药必须看标签 | 部分依赖 6。先要排除养护本身的问题。和 7b 相互独立 | 检查：有没有先确认是哪种虫？有没有提安全间隔期、适用作物？ |
| 7b | **授粉和结果**（只在种果菜时需要） | 花要授粉才能坐果，阳台上昆虫少 | 依赖 1、5。先排除光照不足和氮肥过多 | "小番茄开花不坐果，直射 5 小时，最近施的是高氮肥。请分别评估光照、授粉、施肥三种可能。" |

**哪些是真依赖，哪些是教学建议**：1 → 2、3 → 4、(1、4、5) → 6 是理解上真正的依赖。3 放在 2 后面、7a 和 7b 放在最后，只是教学上的建议顺序：种叶菜的话可以完全跳过 7b。

**建议从第 1 组开始**：今天就在阳台记录一次直射时段。这个数字是你以后每次问 Agent 都要先给的。
