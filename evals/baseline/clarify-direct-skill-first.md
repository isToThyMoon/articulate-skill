没有页面材料，我没法判断“高级”具体差在哪里，所以下面这段要求让 Agent 先看页面、找出具体原因，再动手。“高级”先保留原词，作为有待解释的目标。

---

**给 Agent 的要求**

**对象**：网站首页，只改首页。如果改动会影响其他页面共用的组件，比如导航、按钮、页脚，先列出受影响的地方再决定。

**目标**：让首页看起来更“高级”。这个词还没有明确定义，不要直接套用固定的风格模板，比如深色配金色、大留白配衬线字体。风格方向要从现有品牌、页面内容和页面主要任务推导出来。

**第一步：诊断，先不改**
1. 记录现状：品牌资产（logo、品牌色、字体）、首页的主要任务和核心行动（例如注册、咨询、购买），以及各个板块的内容。
2. 找出让页面显得“不够高级”的具体原因，每条都写明在页面上的位置和截图。可以对照下面这些常见原因，只写实际存在的：
   - 视觉层级不清：首屏没有明确的焦点，或者焦点和核心行动对不上
   - 信息密度过高：元素太多，彼此抢注意力
   - 排版不统一：字号、字重、字体种类太杂
   - 用色不收敛：颜色太多，或者饱和度、色调不统一
   - 间距没有统一刻度：对齐不严
   - 图片风格不一：素材质量或风格参差不齐
   - 组件样式不一致：圆角、阴影、按钮样式各不相同
   - 文案冗长或语气不统一
3. 根据诊断提出 2–3 个候选风格方向。每个方向写清楚：依据哪些品牌或内容特征、主要改哪些地方、有什么取舍，并附首屏的对照示意。**提交给我确认后再实施。**

**第二步：确认后实施**

**约束**：
- 不删减首页现有的信息内容和功能，核心行动的路径不能变长。
- 沿用现有品牌标识。
- 以下几项是否允许，还没确认，需要时先提出来：改文案、替换图片、调整板块顺序。

**验收**：
- 提交改动前后的对照截图，包括首屏和整页，覆盖项目已经支持的所有设备尺寸。
- 每项改动都能对应到诊断里的某个具体问题，并说明怎么解决了它。
- 样式有收敛。下面的数值是建议，不是硬性门槛：
  - 字号层级控制在 5–6 级左右
  - 颜色控制在品牌色、中性色和一个强调色以内
  - 间距用统一的刻度
- 说明改完后首屏的视觉焦点是什么，以及它和页面主要任务是不是一致。

**失败模式**：逐项检查，并附上证据。
- 为了显得“高级”牺牲了可读性，比如浅灰小字、低对比度。文字对比度不能比原来低，建议正文满足 WCAG AA 标准（4.5:1）。
- 核心行动按钮被弱化，或者被挤出首屏。
- 留白加大后，关键信息被推到首屏以下。
- 只换了颜色和字体，层级和拥挤的问题还在。
- 新加的大图、字体或动效拖慢加载。需要对比改动前后的加载表现。
- 修改共享组件时影响到了其他页面。
