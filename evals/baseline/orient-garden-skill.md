**阳台种菜：领域地图与核心概念顺序**

**范围说明（暂定）：** 本回答针对城市住宅阳台，用盆或种植箱种常见蔬菜：叶菜、果菜和香草。内容按零基础来写。本次不展开水培和鱼菜共生、补光灯选型、果树、农药化学，也不涉及露地或规模化种植。本次没有联网核查，内容来自我的已有知识。播种月份和病虫害这类随地区、季节变化的内容，请对照当地农技资料和种子包装说明。文中的"4 小时""6 小时""深度 15–20 cm"等数字是常见的园艺经验值，不是正式标准。

**领域骨架：** 阳台条件（光、温度、风）决定能种什么。选好的作物决定用多大的盆和什么土。盆和土决定怎么浇水、施肥。植物长出来的样子，是检验前面每一步的证据。

## 一、领域地图

| 维度 | 内容 |
|---|---|
| 对象 | 阳台（朝向、是否封闭、承重）、容器、基质（盆土）、作物、害虫与益虫。朝向和遮挡决定每天的直射时长，所以阳台条件对"能种什么"约束最强。 |
| 关键原理 | 光照需求：一般说叶菜每天约需 4 小时直射，番茄、辣椒这类果菜约需 6 小时以上。根部需要水和空气同时存在：浇水太多会挤走空气，根就会烂。盆土里的养分有限，要靠施肥补充。果菜要结果还需要授粉。 |
| 常用词 | 全日照/半日照：直射时长的等级。椰糠、珍珠岩：让盆土透气、保水的材料。缓释肥：慢慢释放的底肥。水溶肥：兑水浇的追肥。定植：把苗种到最终的盆里。间苗：拔掉过密的苗。摘心/打顶：掐掉顶芽，让植株分枝或控制高度。 |
| 做事流程 | 记录日照 → 按光照和季节选作物 → 准备盆和土 → 播种或买苗 → 定植 → 浇水、施肥、观察 → 采收 → 换下一茬并处理旧土。出了问题，要回到"光照、浇水、施肥"中对应的一环调整。 |
| 要留的记录 | 日照记录：几点到几点有直射。种植计划：什么作物、哪个月种。浇水施肥日志和问题照片。这些是向 Agent 求助、做诊断时最有用的材料。 |
| 怎么判断好坏 | 看植株：茎粗不粗、节间（两片叶之间的茎段）长短、叶色、有没有新叶。看土湿：手指插下 2–3 cm 试，或掂盆的重量。最后看产量。取舍在于投入的时间、空间，与收成是否相称。 |
| 常见失败 | 徒长：茎细、节间长、叶色淡，多半是光不够。烂根：土是湿的但植株萎蔫。黄叶：老叶先黄常提示缺肥（可能是缺氮）。蚜虫、红蜘蛛：后者在干热阳台多见。只开花不结果：可能是授粉不足或温度太高。 |
| 可依据的规范 | 阳台种菜没有统一的正式标准。可以参考的有：种子包装上的播种说明、各地农技推广部门的蔬菜种植日历，以及物业关于阳台承重和防止高空坠物的规定。 |

## 二、向 Agent 提问与判断回答

**提问时交代这些条件：**
- 所在城市（气候）和当前月份
- 阳台朝向，是否封闭，实际直射时段（例如 9–13 点）
- 能放几个盆，每个盆多大、多深
- 想吃什么
- 每天能花多少时间照料
- 能否接受化学药剂

**回答比较可靠的信号：**
- 先问光照、地区和季节，或者按这些条件分情况给建议（"如果直射少于 4 小时……"）。
- 浇水建议是"先检查土湿再浇"，而不是"每天浇一次"。
- 诊断问题时列出几个可能原因，并告诉你怎么区分它们。
- 给出盆的具体深度，并提醒承重和防坠落。

**值得警惕的回答：**
- 不分地区给统一的播种日期。
- 照搬露地的种植密度。
- 向小阳台推荐南瓜、西瓜这类很占地方的作物，却不说明空间要求。

## 三、核心概念与理解顺序

| 顺序 | 概念 | 先决项与理由 | 向 Agent 的要求或检查问题 |
|---|---|---|---|
| 1 | **光照**：每天直射的时长和时段 | 没有先决项。它是约束最强、最难改变的条件。 | "我的阳台朝东，每天直射约 4 小时，列出适合种的蔬菜并说明理由。" |
| 2 | **作物分类 + 季节窗口**：叶菜/果菜/根菜/香草对光和空间的需求不同；有的作物喜凉，有的喜热 | 先理解光照，才能判断哪类作物种得好。季节和光照互不依赖，放在一起学只是教学安排。 | 检查问题：它推荐的作物，光照需求和当前季节都对得上吗？ |
| 3 | **容器与根系空间**：盆的体积、深度、排水孔 | 需要先确定种哪类作物。例如叶菜常说 15–20 cm 深就够，果菜要更深更大。 | "按我选的作物，给出每盆最小深度和容积，并说明依据。" |
| 4 | **盆土透气保水 ⇄ 浇水判断**（两者要一起理解） | 盆土决定水留多久，浇水频率取决于盆土、盆的大小、光照和温度。所以浇水不能照日历来。 | 检查问题：它的浇水建议是否以检查土湿为前提？ |
| 5 | **养分与施肥**：氮主要促进长叶，磷、钾与开花结果有关；宜少量多次 | 先理解盆土养分有限（第 4 项），也要先知道种的是叶菜还是果菜（第 2 项）。 | "按作物和生长阶段，给出施肥类型、浓度和间隔，并说明施多了会有什么症状。" |
| 6 | **授粉**（只涉及果菜） | 需要先理解作物分类。封闭阳台缺少昆虫，可能要人工授粉。 | 检查问题：它有没有区分"花没授上粉"和"温度太高导致落花"？ |
| 7 | **症状诊断**：徒长、黄叶、萎蔫、虫害 | 需要前面各项。每种症状都要回到光、水、肥、授粉中去找原因。 | "附上照片和浇水施肥记录，请列出几个可能原因，并给出区分每个原因的检查办法。" |

**推荐从第 1 项"光照"开始。** 先花一两天记下阳台几点到几点有直射，后面每个问题的答案都会跟着这个数字变化。

需要的话，我可以拿一个具体阳台（比如"朝东、每天 4 小时直射的封闭阳台，秋季种叶菜"）从头走一遍：怎么选作物、写出种植计划，再到出问题时怎么诊断。
