# 阳台种菜：领域地图与核心概念

## 一、领域地图

| 维度 | 内容 |
|---|---|
| **目标** | 吃到自己种的菜，最好稳定、持续地收；顺带绿化和解压。新手最现实的目标是先种活、再高产。 |
| **硬约束**（阳台自己决定，很难改） | ① 光照：朝向、每天直射几小时、有没有玻璃遮挡；② 温度：所在气候区、季节、楼层高低、风大不大；③ 空间和承重：面积、栏杆和墙面能不能挂东西、湿土很重；④ 排水：浇的水会不会滴到楼下。 |
| **可调变量**（你能选、能控制） | 作物和品种、容器、基质、浇水、施肥、播种时间、支架和修剪、补光灯。 |
| **生长过程** | 种子发芽 → 育苗 → 移栽 → 长茎叶 → 开花授粉 → 结果或长成可收的部分 → 采收 → 换茬（上一茬收完接着种下一茬）。 |
| **常见问题** | 缺光导致茎细长发软（徒长）；浇水过多导致烂根；缺肥或基质失衡导致叶片发黄；天热或日照变长导致叶菜过早开花（抽薹）；没授粉导致只开花不结果；病虫害，常见的有蚜虫、红蜘蛛、白粉虱、白粉病、土里的小黑飞虫（菌蚊）。 |
| **判断依据** | 植株长势（节间长短、叶色、叶片形状）、基质湿度（手指插进土里或掂盆的重量）、产量、根的颜色（白色健康，褐色发黑有问题）。 |
| **子流派** | 普通土培（主流）、水培、生态箱（自动吸水盆）、垂直种植、室内补光种植。 |
| **信息来源** | 种子包装背面（写着播种期、株距、生长天数）、当地农业部门的播种日历、园艺论坛。经验帖受地区影响很大，别地的经验不一定适用。 |
| **常见争议** | 有机肥还是化肥；是否用农药、用哪种；泥炭基质的环保问题；按固定时间浇水还是看土的干湿再浇。 |

**整体逻辑**：光照和温度决定你能种什么，容器和基质决定根长得好不好，浇水和施肥决定植株长势，授粉和病虫害决定最后能收多少。

## 二、核心概念（按理解顺序排列）

前面的概念弄不懂，后面的概念就判断不准。

**1. 光照：每天直射小时数**
这是最根本的限制，不是阳台亮不亮就行。
- 果菜（番茄、辣椒、黄瓜）一般要求直射 ≥ 6 小时。
- 叶菜（生菜、菠菜、小白菜）约 3–4 小时也能长。
- 北半球朝南的阳台最好；朝东只有上午的光；朝西下午晒而且热；朝北基本只适合耐阴叶菜。
- 封闭阳台的玻璃会减弱光照，也会挡掉一部分紫外线，实际能用的光比看起来少。

**2. 温度与季节：冷季作物和暖季作物**
- 冷季作物（生菜、菠菜、豌豆、萝卜）喜欢大约 15–20°C，天热容易抽薹、发苦。
- 暖季作物（番茄、辣椒、瓜类、罗勒）怕冷；天太热（大约超过 32–35°C）也会不容易坐果（开花后结不成果）。
- 什么时候播种取决于你所在的地区，没有全国统一的时间表。

**3. 作物类型（依赖 1、2）**
按吃的部位分四类：叶菜、根茎菜、果菜、香草。
- 从叶菜到果菜，对光照、容器大小、养分、授粉的要求依次升高。
- 新手最稳的是叶菜和香草，其次是小番茄和辣椒。

**4. 品种（依赖 3）**
同一种菜，不同品种适合阳台的程度差很多。要知道这几个词：
- 矮生或盆栽品种：长得矮，适合容器。
- 番茄分"有限生长"和"无限生长"：有限生长的长到一定高度自己停，无限生长的会一直往上长，要搭架、要修剪。
- 单性结实的黄瓜：不用授粉也能结果，适合没有昆虫的阳台。
- 耐抽薹的叶菜品种：天热或日照变长时不容易过早开花。

**5. 容器（依赖 3、4）**
重点看三样：体积、深度、底部排水孔。
- 叶菜深约 15–20 cm 就够。
- 番茄单株最好 ≥ 15–20 升。
- 容器越小，土干得越快、温度变化越大，越难管理。

**6. 基质（依赖 5）**
容器里不能直接用院子里的普通土，它会板结、不透气。
- 常见配法：泥炭或椰糠为主，加珍珠岩或蛭石增加透气，再加有机质。
- 好基质要同时做到保水和透气。
- 酸碱度一般在 pH 6–7 之间。

**7. 浇水（依赖 5、6）**
根也需要呼吸，所以"积水"比"偶尔干"更危险。
- 原则是见干见湿：表层 2–3 cm 干了就浇，浇就浇透，让水从盆底流出来。
- 浇水间隔随天气、盆的大小、植株大小变化，不是固定的。

**8. 养分与施肥（依赖 6、7）**
- 常说的三种主要养分是氮、磷、钾（N-P-K）。大致上，氮促进长叶，磷和钾促进开花结果。
- 施肥方式主要两种：缓释肥作底肥（慢慢释放），水溶肥作追肥（见效快）。
- 容器里的养分会随浇水流失，需要定期补。
- 肥施多了会"烧根"，让根受损。
- 叶子发黄的原因很多，不一定是缺肥，可能是浇水、光照、根的问题。

**9. 播种与育苗（依赖 1、2、6）**
- 每种菜有自己合适的发芽温度。
- 有的菜适合直接播在最终的盆里（直播），有的适合先育苗再移栽。
- 苗期光照不足，茎会细长发软，这叫"徒长"。
- 移栽前要先让苗逐渐适应室外环境，叫"炼苗"。

**10. 授粉与坐果（依赖 3、4）**
阳台上昆虫少，这是结不出果的常见原因。
- 番茄是自花授粉，开花时轻轻摇动或震一震花就行。
- 瓜类分雄花和雌花，一般要人工把雄花的花粉抹到雌花上，除非选了单性结实品种。

**11. 病虫害诊断（依赖以上全部）**
- 同一个症状可能有好几种原因，要结合环境一起看，比如：
  - 红蜘蛛：天气干热时多。
  - 菌蚊（土里的小黑飞虫）：基质太湿时多。
  - 白粉病：不通风时多。
- 防治思路是先改善环境，再考虑用药。
- 给吃的菜用药，要看"安全间隔期"，也就是最后一次用药到可以采收之间必须等的天数。

**12. 采收与持续产出**
- 叶菜可以只摘外层叶子，留着中心继续长。
- 每隔一段时间播一小批（分批播种），就能一直有得收。
- 一茬收完，要换新基质或给旧基质补充养分，再种下一茬。

**另外，安全要单独考虑**：检查承重（湿土大约每升 0.6–1 kg），盆和架子要防坠落，排水别影响楼下。

## 三、怎么向 Agent 提问

提问时最好带上这几项信息：

> 我在【城市/气候区】，阳台朝【方向】，【封闭/开放】，每天直射约【X】小时，【X】楼，风【大/小】。现在是【月份】。我想种（或已经在种）【作物 + 品种】，容器是【尺寸/容积】，基质是【成分】。目前在【生长阶段】，出现了【具体症状：部位、颜色、从哪里开始、持续几天】。最近的浇水和施肥情况是【……】。

如果只能给一项，就给**直射小时数**。

## 四、怎么判断 Agent 的建议靠不靠谱

**值得警惕的信号**
- 没问你的光照、地区和季节，就直接推荐作物或给出播种时间。
- 给固定的浇水频率，比如"每天浇一次"，不说要看土的干湿。
- 建议直接用院子里的普通土上盆。
- 一看到叶子黄就让你施肥，不提其他可能原因。
- 果菜不结果时不提授粉。
- 推荐农药时不说安全间隔期，或推荐不能用在食用作物上的药。
- 给出很精确的数字，却不说明前提条件（地区、品种、容器大小）。

**比较可信的信号**
- 按条件分情况给建议，比如"如果直射少于 4 小时，就……"。
- 解释了背后的原因，比如为什么要见干见湿。
- 给出你自己能动手验证的方法，比如手指插土、掂盆的重量、看根的颜色。
- 诊断时列出几种可能的原因，并告诉你怎么一一排除。
