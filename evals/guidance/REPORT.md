# 正向引导重写与有界行为测试

## 写作标准

1. description 以真实触发分支为主，三个入口各有主责。
2. 主文件呈现目标、关键判断、步骤和可观察完成条件。
3. 正向描述期望行为；保留必要授权与学习档案边界。
4. 通用方法单点维护，分支引用注明何时读取；安装包自包含。
5. 八类负责覆盖、五层负责理解，输出按人的问题组织。
6. 事实、假设、建议及要求强度在可复制表达中保持一致。
7. 篇幅优先给影响理解、选择和验收的内容。
8. 行为测试检查实际结果，格式检查只验证包装。

writing-for-agents 用于重组信息层级、正向步骤和单一事实源；skill-creator 用于检查范围、按需引用、独立安装与验证。此处将正向引导作为写作策略，不宣称删除否定句必然提高所有模型的表现。

## 本轮审查与变化

| 部分 | 发现 | 改动 |
|---|---|---|
| orient | 主入口同时容纳全景、翻译、执行、考核，路径过宽 | 聚焦地图、学习导航及知识库；具体澄清与材料拆解各有入口 |
| clarify | 共同边界重复，收束标准被解释性文字包围 | 意图—关键区别—可用表达；保留 Object / Dimension / Constraint / Metric / Failure Mode |
| deconstruct | 独立审查阶段易把学习变成挑错 | 校准证据与概念解释并置，区分一般含义和本例用法 |
| 共同方法 | 证据要求分散，复制时容易增加范围或强度 | 统一证据身份、建议性质和要求强度 |
| 地图与学习 | 细节积累、紧凑请求仍易长篇 | 紧凑地图与学习组的呈现路径；案例区分检查计划和观察结果 |
| 知识库 | 边界重述较多 | 查重—组织—合并—检查，保留确认位置、增量更新与冲突处理 |

## 测试设置

复用已有 GPT-5.6 Sol 测试会话；向 agent 提供当前技能路径与真实用户请求，读取要求的引用。此次均禁止联网，验证交互与表达，不验证在线检索质量。此前历史会话可能影响输出，因此不是新上下文盲测，也不是改前/改后的受控 A/B 实验。

### Clarify

A：“这个页面很乱，帮我把意思说专业一点。”无页面材料。

[首轮输出](clarify-first.md)中的 A 给出三个候选解释，问一个关键问题并等待。满足本轮交互目标。

B：“我想让首页更高级，别追问，直接给我一段交给 Agent 的要求。”无页面材料。

- [首轮](clarify-first.md)：保留部分不确定性，但添加桌面和移动端交付范围，篇幅偏长。未通过范围检查。
- [第二轮](clarify-second.md)：范围缩小，但自行把高级解释成克制、精致。未通过意图保留检查。
- [最终复测](clarify-final.md)：高级保留为待解释目标；风格成为待确认建议，范围未知可见，含检查与验收。达到本场景标准。

输出仍有否定句；本轮目标是以引导为主，并非对自然语言作零否定句限制。

### Deconstruct

请求简短解释给定评审：可把低频设置放进更多选项，用渐进披露减少首次信息；需要确认可找到，并检查常用任务是否多一步。没有实际界面。

- [首轮](deconstruct-first.md)：概念解释清楚，但将检查是否多一步写成不增加步骤，强化了要求。
- [第二轮](deconstruct-second.md)：恢复取舍，但概念定义仍过于贴近低频设置这一用法。
- [最终复测](deconstruct-final.md)：区分一般概念与本例，给出变化情境，保留可发现性与交互成本的取舍，复制段落条件明确。达到本场景标准。

### Orient

请求：“我想进入 UI 设计领域，先给紧凑的领域地图，然后选核心概念按理解依赖排列；不要联网，不要问问题。”

首次输出完成八类、离线说明和学习顺序，但篇幅明显偏长，案例评价以计划为主。据此加强紧凑呈现与明确模拟观察的交付条件。

[首次原文](orient-first.md)与[最终复测](orient-final.md)均保留。最终输出用八行地图和依赖表，同轮完成两项请求，包含产物片段、明确模拟观察和修订决定，离线来源缺口可见。字符数由 7373 降为 3633（含 Markdown 和空白）；达到本轮结构与案例标准。剩余可读性取舍：表格单元格仍较密，全文对只想快速扫读的人仍偏长；不据此宣称已取得普适最佳篇幅。

## 验证范围与限制

三个 skill 的 frontmatter 校验、共享副本一致性与本轮 Markdown 引用检查通过；本地安装副本同步。未改默认自动发现策略，未提交或推送。

本轮没有重新实测联网来源获取、真实文件知识库增量合并、跨领域迁移与多模型差异。现有历史测试仅是历史依据，不能视为新版本全部行为的回归通过。本轮结论限于所展示的请求；修订后同会话通过，也不能证明新会话首次稳定通过。

保留的取舍：orient 的八类首轮地图天然比单问单答更长；共同方法在每个独立安装包携带副本，但维护源只有一处；关键授权边界继续明确陈述。实际收益仍应由真实用户对可理解性、可执行性及结果质量的反馈验证。
