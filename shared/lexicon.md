# 可复用领域知识库

保存能帮助理解、表达和判断的知识，按共同方法的八类导航、五层组织内容。

## 进入与定位

用户明确要求保存、整理、检索或更新知识时进入。使用已指定或确认的库；位置未定时建议一个位置并确认，期间可先展示候选条目。

检索与应用只读取库；写入走下方保存流程。更新限于请求范围，广泛重组或删除另行确认。保存选定知识，私人项目细节与完整聊天按明确授权处理。

## 保存与更新

1. **查重**：读取索引及相关条目，用名称、别名和问题描述检索；同义项补别名，同名不同义分开。完成时明确新增还是更新。
2. **组织**：提取有复用价值的知识，以相关五层组织，缺口标待补或未核实；项目参数保留为场景条件。完成时条目能解释何时使用。
3. **合并**：增量更新，保留人工备注、稳定标识、已有链接和无关内容。冲突核对范围、版本与来源，未解决则并列说明。完成时新旧内容及争议均可追溯。
4. **检查**：更新索引、核对内容与真实链接，告知位置及新增、补充和未决事项。待建关联先写概念名。完成时改动范围与请求一致。

沿用已有布局；新库可用 index.md 提供按领域和问题检索的入口，entries/ 放条目。八类作为索引角度，条目可跨类。

## 条目内容

按内容合并段落，保留以下有用信息：

- 名称、领域、别名与相关类别。
- 定义、问题、机制及适用边界。
- 概念关系及条件、易混淆项；有真实反义或反模式时分别解释。
- 使用阶段、输入、决策、产物和反馈。
- 判断依据、取舍、失败模式和证据缺口。
- 一个调用情境及可移交的 Agent 提问或要求。
- 来源支持什么，属于用户材料、外部证据、内化解释还是教学假设；时效主张记录已知版本及实际核查日期。

## 检索与应用

从对象、目标或症状检索，读取条目的条件、关系与依据，选择能改变本次判断的知识。

形成：原始诉求 → 当前对象与观察 → 概念及关系 → 条件与选择 → 可执行要求 → 验收与失败边界。

旧案例用作参考，当前事实、版本和约束依据本次信息确定。证据不足时交付诊断要求或条件化方案。

完成标准：条目可被找到，知识解释何时使用，最终要求可移交。
