# 来源与交叉检查

## 1. 建候选结构

用内化知识拟定子域、八类内容、关系及待查主张。优先识别遗漏分支、易混概念、条件性建议和版本/地区差异，以这些问题引导查找。

完成条件：有可修订结构和影响判断的检索问题，交付时只呈现整合后的地图。

## 2. 获取互补资料

新领域地图尝试以下途径，已有可靠材料可复用。类别代表用途，同一来源可承担多种作用。

| 途径 | 获取与使用 |
|---|---|
| 概览 | 教材目录、课程大纲、综述或专业组织介绍，核对范围；具体结论以正文为依据 |
| 规范与官方文档 | 原始发布文件，校准定义、规则、范围和版本，区分规定与实现 |
| 真实专业产物 | 有实际组织或项目背景的方案、规范文档、决策记录、研究与评审记录（如软件的 RFC、ADR，医疗的临床路径，建筑的图纸会审），提取决策与代价 |
| Checklist | 有适用背景的评审或验收清单，提取观察项并检查适用条件 |
| 失败案例与研究 | 当事团队复盘、真实可用性研究、缺陷或实验报告，提取症状、原因证据及局限 |

真实产物具有项目及决策背景；模板用于理解结构。通用反模式用于解释机制，真实复盘提供事件证据，教学案例用于演示——各自标明用途。

从领域词结合产物类型或具体问题检索，追到发布方、公开仓库与原始研究。一般入门也查实际产物与失败案例；相邻场景的材料可以补充机制，同时交代迁移边界。

资料不可访问时寻找合适替代；合理尝试后仍缺少的类别写明缺口。完成条件：各途径有可用内容或清楚的获取限制。

## 3. 按主张核查

读取支持段落，搜索摘要用于定位。关键规则、易混淆概念和高风险判断比较互补证据；具体案例、数值及例外逐项对应来源。

规范解释预期，产物显示采用方式，失败案例揭示边界。效果主张优先依据实验、研究或测量，区分观察与因果解释。证据来自不同项目时分别表述。

冲突核对定义、版本、地区、样本、任务和目标，形成条件化结论或保留分歧。资料可确认、补充分支或收窄建议，按实际结果修订。

维护简短对应：资料及场景 → 支持或限制的主张 → 地图落点。完成条件：主要分支经核对，关键判断有依据，各类来源有贡献或缺口，重要冲突已处理或保留。

## 4. 呈现依据

具体出处靠近支持的主张，导航简述资料对地图的实质贡献和仍缺的证据。基础解释保持流畅，综合推断与来源事实在会影响理解的位置区分。

离线时基于内化知识交付候选地图，明确未做外部核查、时效性规则待确认及来源缺口。已有用户材料仍可检查。
