# Deconstruct

从具体材料学会专业人士在区分什么、凭什么下结论，以及这些知识何时值得调用。

开始时读取 [共同方法](references/foundation.md)。八类定位知识，五层连接含义、判断和使用。

## 1. 定位材料与问题

使用用户指定的材料；“刚才的回答”在上下文可定位时直接使用。材料不可访问时说明缺口并请求有关片段。

确定原文试图解决的问题与拆解范围。单个概念聚焦语境；一般请求选择核心概念组；要求全部时完整覆盖约定范围，长材料明确分段。

完成条件：开头一两句点明原文在解决什么问题；材料多段或较长时写明拆解范围与分段；原文内容与补充知识可以区分。

## 2. 沿结论拆知识

用八类识别相关内容，再把共同方法的五层逐层落到原文的核心结论上：原词在本语境的含义，概念让原文得出哪个结论或建议、又给它加了什么限制，这一步发生在工作流哪里，什么证据会支持或推翻它。

以概念组或问题自然组织。原文内容用短引文或位置锚定；推断和补充知识在相关处说明。某层材料不足时指出具体缺口。

区分概念的一般含义与原文中的具体用法；把本例的适用条件限定在本例，便于用户迁移到不同情境。

把证据校准放在相应概念旁：准确之处说明成立条件；存在误用或过度推断时，指出对应片段并给更准确的说法。分析前提时区分逻辑必要条件、经验上有利条件和可选策略；作者意图以文本证据为准。

完成条件：原文每个核心结论都能追到依据它的概念及适用条件；材料不足的层次写明缺口。

## 3. 迁移到表达

给一个短小的变化情境，说明何时会想到这些概念、条件改变后怎样调整；再给一条可移交的 Agent 提问或要求，覆盖核心概念组。教学情境明确标为假设。概念组彼此独立且用户要求完整拆解时，才逐组给出。

正文按概念或问题讲知识与依据，最后给可复用表达。单词解释可合并为几段，深度服从用户需要。改写整份材料按明确请求进行。

完成条件：有一个变化情境和一条可移交表达，覆盖核心概念组；事实、原文主张和假设各自标明。

用户明确要求保存或检索知识时，读取 [知识库](references/lexicon.md)。
